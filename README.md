# 🎯 Flutter Quiz App

Aplikasi mobile kuis interaktif yang dibangun menggunakan Flutter dengan antarmuka yang modern dan responsif.

### 🛠️ Tech Stack
- Flutter SDK & Dart
- Multiplatform (Android & iOS)

### ✨ Fitur Utama
- Alur pertanyaan kuis bertahap (*Step-by-step questions*)
- Tombol pilihan ganda interaktif
- Halaman hasil (*Result Screen*) dan evaluasi ringkasan jawaban (*Summary Item*)
